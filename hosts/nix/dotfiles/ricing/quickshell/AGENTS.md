# Quickshell UI

Use [native service and component contracts](../../../../../docs/reference/quickshell.md) for API work and [launcher contracts](../../../../../docs/reference/launchers.md) for app/tool/gallery changes. Source ownership paths below are repository-relative.

- `hosts/nix/modules/home/quickshell.nix` deploys the `expressive` configuration, command dependencies and restart trigger. Read the pinned package's `.qmltypes` or matching upstream tag before assuming an API.
- Use native Quickshell services and Qt controls, not subprocess polling or replacement input stacks. `ShellRoot` owns shared services/IPC; `Variants` owns per-screen panels. Native workspace/audio/service objects are disposable: guard null/ready state, never retain deleted native objects in persistent JS state. Wait for PipeWire `node.ready`; volume is fractional. Hyprland dispatch uses Lua `hl.dsp.*`, not legacy strings.
- External data travels as argv, never shell interpolation. Keep the GIO bridge's visibility/action-membership rechecks and terminal/working-directory/field-code semantics. Utility selection uses exact model values, not raw search; VPN names retain trailing spaces. Preserve revision guards against stale completions. Night-light requires exit success **and** an `ok` response.
- Preserve Tab/Backtab, accessible action names, keyboard-only focus rings (`visualFocus`, or TextField `focusReason`) and reduced motion. Reuse native Basic-style controls and shared expressive components rather than caller-specific input/animation logic. Keep bundled palette-tinted Boxicons for shell-owned icons; app-provided icons stay external.
- Hyprland owns surface animation; no QML resize springs or first-frame gates. Keep compact, screen-clamped popovers, on-demand layer focus, bounded focus grabs, outside-click/Escape dismissal and zero popover/OSD reservation. `QS_REDUCED_MOTION=1` selects the nonanimated layer namespace. Launcher and rail popovers remain mutually exclusive.
- Tray menus use native models with `Popup.Window`; device menus use `Popup.Item`. Detach loader-owned entries with `takeItem`/`takeMenu`, never destructive removal. Notifications are tracked on delivery; retain expired history with `RetainableLock`, release on close, disable expired actions and respect millisecond timeouts.
- `Theme.qml` reads writable runtime `quickshell/colors.json`, reloads changes and keeps the last valid palette. Do not deploy that output. Color properties use `textOn*`, not QML handler-like `on*` names. UI family is `Google Sans Flex`; emphasized style is `Bold Rounded`.
- Candidate runs require both a separate compositor and D-Bus session. Never displace the running notification daemon or change live audio/network state. Before nesting Hyprland, snapshot `WAYLAND_DISPLAY`, `DISPLAY`, `HYPRLAND_INSTANCE_SIGNATURE` and compositor/cursor variables, including unset state; restore manager **and** bus activation environments on every exit. Check the restored manager display against `hyprctl instances` before real services start. See [preview isolation](../../../../../docs/reference/quickshell.md#preview-isolation).

When verification is authorized, use the pinned API and isolated preview procedure; exercise keyboard-only and reduced-motion behavior without destructive power actions or live VPN changes. The detailed reference records remaining component geometry, lifetimes and stock-package crash limitations.
